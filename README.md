## You do not need a physics degree!

Seriously. Roughly half the value in a quantum hackathon project comes from knowing what problem is worth solving, and that knowledge lives with people who work in finance, logistics, energy, healthcare, policy, and operations, not with quantum physicists. We will have a presentation that covers all the various roles in quantum, outside those requiring a PhD.

If you're hesitating because you think you're not technical enough, read **[NON-TECHNICAL-TRACK.md](NON-TECHNICAL-TRACK.md)** before deciding. It was written for exactly that hesitation.
